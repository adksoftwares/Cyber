# ARY CyberShield

Defensive security monitoring and policy-management starter.

This repository is being initialized with the ARY CyberShield application package. The application is a defensive control plane, not a hack-back tool.

## Security scope
- Web/API security event ingestion
- Detection indicators for common web attack patterns
- Admin-managed IP denylist and firewall-rule records
- Security event and audit-log APIs
- React dashboard and FastAPI backend
- Docker deployment scaffolding

Real packet-level firewalling, DDoS scrubbing and network IPS require integration with a trusted edge provider or network sensor. IP geolocation is approximate and cannot identify a person or exact physical address.

See the project package README for setup and production-hardening requirements.
